## Unified data path

`RawArtifactStore` publishes exact payload + manifest atomically as `source_id/content_sha256/`. Checksums detect corruption; repeated identical provenance is idempotent and conflicting provenance is rejected. Concurrent writers cannot publish half a pair. A new retrieval with different metadata is a distinct event: current storage preserves the first manifest and rejects rewriting it; the CLI reuses and verifies an existing identical payload. It does not silently replace the original retrieval timestamp.

`CsvMapping` defines columns, original timezone, interval duration, currency, temperature unit and an explicit workload scale. The default columns are `timestamp,workload_compute_units,price_per_mwh,temperature_c`. Mapping defaults are for the documented five-minute USD fixture, not arbitrary vendor data. Missing values stay nullable and are reported; malformed rows, nonfinite numbers, duplicate/overlapping intervals and ambiguous/nonexistent DST timestamps fail explicitly. Temperature outliers and cadence gaps are reported and rejected for simulation pending explicit review/imputation. Original timestamp/timezone and raw digest survive normalization.

`SimulationIntervalV1` stores UTC `[start,end)` intervals, workload totals, optional active capacity, price+currency, ambient, grid conditions/carbon, cooling estimates, quality bits, metadata and lineage. It is separate from live telemetry because interval totals and prices retain source currency. `to_site_inputs` checks contiguous intervals, one site/cadence, required values and explicit currency conversion. Construct `SiteConfig(timestep_seconds=rows[0].duration_hours*3600)` and start the simulator at the first interval start when cadence differs from defaults.

`resample_intervals` conserves interval totals, duration-weights mean rates and takes maximum event severity. Instantaneous/state values forward-fill from already-observed samples only, with optional `max_state_age`; never backfill NOAA temperatures from a future timestamp. Missing coverage is NaN plus an explicit quality bit. Rates and totals reject overlapping sources before resampling. Google task aggregation first sums distinct concurrent tasks into nonoverlapping totals. Resampling uses a sweep/binary search rather than scanning the full source series for each target.

`write_dataset` emits a content-versioned directory containing validated JSONL, Parquet (metadata encoded as JSON strings) and a quality report. `chronological_split` separates intervals by cutoff and drops straddling intervals; learned scaling/imputation must fit training data only. Joining prices/weather/workload is an explicit caller operation: align on UTC interval boundaries using the appropriate signal semantics, retain each input digest in lineage metadata and never label the synthetic workload/power mapping as observed.

## Adding a source

Inspect the official schema/sample and product terms first. Persist exact bytes with reviewed `SourceTerms`; implement a pure bytes-to-signal parser; test timestamp conventions, missing sentinels, units, schema revisions and duplicates using synthetic schema-shaped fixtures. Resample to shared intervals, join with per-field provenance and validate `SimulationIntervalV1`. Add a live check only behind the `external` marker; normal tests must run offline. Keep credentials in environment/private downloaders and out of URLs/manifests. No raw external data is tracked by default.
